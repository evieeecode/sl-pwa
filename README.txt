申论八股操练 PWA

本版更新：
1. 内置句式调整为：
   - 以__为__，__
   - 坚持__，__
   - __，__（第三句两个槽位默认提示为“动词”）
   逗号前槽位默认只放 1 个语块，逗号后默认不限；句式库新增/编辑时可逐格调整。
2. 练习一次只显示当前一句；“下一句”位于语块池下方。第三句完成后按钮变为“完成”，随后显示三句成稿，再点“下一题”。
3. 本期主题词置顶且可直接点击填入；语块池不再重复显示主题词。
4. 开始练习后进入专注全屏，底部导航隐藏，必须主动“退出”才能离开练习；退出后当前计时停止。
5. 支持“正计时”和“倒计时挑战（60 秒）”两种模式。
6. 主题词按同一主题分组抽取 3 个。
7. 通用语块绿色按钮位于所有语块最后；点击立即加入当前槽位，绿色语块可编辑/删除，不限量且仅当前题有效。

部署：通过 HTTPS 静态托管（例如 GitHub Pages）访问后，可在 iPhone Safari 中“添加到主屏幕”。
