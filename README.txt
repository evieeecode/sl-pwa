申论八股操练 PWA

本版更新：
- 句式改为“槽位 + 自由语块”模式：一个槽位可以放多个语块。
- 三个分论点独立排句，必须手动点击“下一句”，不会自动跨句串词。
- 主题词置顶，动词/比喻词/效果分栏显示；题目主题词默认从同一语料分组抽取 3 个。
- 通用语块改为底部绿色按钮：点击后直接插入当前句当前槽位，点绿色语块即可编辑；不限量，仅当前题有效。
- 句式库编辑新增“每个空是否默认 1 个语块”的设置。
- 移动端 UI 压缩、分类配色、语块填入动效、长按拖动排序。

运行：
1. 不要直接用 file:// 打开；Service Worker 需要 http/https 环境。
2. 将整个文件夹放到静态网站托管。
3. iPhone Safari 打开网址后，可“分享 → 添加到主屏幕”。

数据：
- 语料、练习记录、打卡、XP、当前练习均保存在 IndexedDB。
- 设置页可导出/导入 JSON。
- 通用语块不会写入语料库，也不会形成历史库。
